# Learning by building

This is the first published Markdown note. Articles are loaded at build time — no database and no admin backend.

## What belongs here?

- Networking and infrastructure deep dives
- Linux administration and troubleshooting
- DevOps experiments and postmortems
- Programming notes, diagrams and practical code

## A code example

```bash
ip route
ss -tulpn
```

## Images and links

Place public media files inside `public/media/` and reference them with `![Alt text](/media/example.png)`.

You can also embed a YouTube video using a normal iframe in an article component in a future enhancement; raw HTML is intentionally not executed in Markdown.

> Articles become visible only when `publish: true`. Never put private notes in a public Git repository.
